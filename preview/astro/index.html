前言

把 learngrok.dev 与 grokbot.dev 的核心内容整理成中文。强调「把工作交给 Bot，而不是反复提问」，并按清晰模块组织。

阅读次数： 0

核心原则

Give a Bot the job, not the question

清晰的岗位描述比临时提示更重要。把长期规则写进 Bot 描述。

一个 Bot 一个岗位 + 先验证再自动化

先搜索现有 Bot。流程做对后再保存为 Skill，稳定后再挂例程。

连接器与 Skills

优先使用连接器。Skill 应写明：何时使用、输入、步骤、如何验证、输出格式、哪些动作必须审批。

实操测试

测试：先搜索再设置例程

先搜索是否已有适合做每日邮件摘要的 Bot。如果有就用它；没有再建议。然后让它保存例程：每个工作日 8:30 生成最多 5 条未读邮件摘要。无新邮件时回复「今日无新邮件」。不要发送任何邮件。
